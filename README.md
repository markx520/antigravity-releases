# Antigravity 跨平台桌面客户端全版本官方发行中心

本项目为 Google Antigravity 跨平台桌面客户端官方原生安装包、核心整包与历史版本资产分发中心。

---

## 1. 架构定位与发布规范

遵循纯血极简与官方发布资产标准，本仓库实行**整包资产化发行规范**：

- **零解包散装代码**：代码主干不包含任何散装反编译或解包碎片，极致守护代码纯净度与官方原生完整性；
- **全生态整包分发**：所有官方各个历史版本（Windows 原生安装包 `.exe` / 商店便携包 `.msix`、macOS 原生通用包 `.dmg`、跨平台核心运行时整包 `app.asar`）统一在 GitHub **Releases 发布资产区** 提供完整下载；
- **真实完整性保障**：每个整包资产均附带官方原生哈希校验码，确保开箱即用、无二次污染。

## 3. 资产下载与快速上手

### 获取对应版本整包
1. 访问本仓库右侧导航栏的 **Releases** 列表；
2. 选择目标版本标签（例如 `v2.19.1` 或 `v2.18.1`）；
3. 在该版本的 **Assets** 附件列表中直接下载对应平台的完整安装包或核心运行时整包。
